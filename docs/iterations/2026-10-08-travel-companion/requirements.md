# 旅行随行功能

基于 master 78b1adf，本轮保留旅行/Fitness 一级导航，以及旅行空间 local-first、Fitness 账号级隔离。

- 旅行计划内提供行程、小票、开口三个页签；首页提供小票和日语入口，并将所选日期传入详情。
- 日期横栏显示完整日期；按旅行时区定位今天，其他日期明确显示预告/回顾。地点详情用底部弹层展示停留、交通和临场提示。
- 小票保存在当前旅行，允许独立选择消费日期、填写商家、分类和正整数日元金额。相同旅行内按日期 + trim/lowercase 商家 + 金额防重；删除需确认；展示当日分类及全程合计。
- 真实账本不自动创建任何示例记录，不与任务预算相加。
- 日语提供交通、餐饮、住宿、求助分类，复制实际日语文本；明确说明未接入朗读。
- 延误情景只模拟当天整体顺延 15/30/60 分钟，不提供应用到正式行程操作。关闭、切日、切页签、页面隐藏时清除。
- 不调用付费 API，不提供预订，不推送、发布或部署。
